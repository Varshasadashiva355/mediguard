# MediGuard AI – PTB-XL Dataset Setup Guide
## Multi-Label Diagnostic Superclass Classification Pipeline

> **Non-Negotiable Rule 1:** MediGuard AI is a clinical decision-support research prototype, NOT a standalone diagnostic device. ML scores are experimental decision support.  
> **Non-Negotiable Rule 5:** All patient data used in deployment is strictly synthetic. Training utilizes the public open-access PTB-XL research benchmark under CC-BY 4.0.

---

### 1. Dataset Overview

**PTB-XL v1.0.3** is a large, publicly accessible, clinically validated database of 21,799 clinical 12-lead electrocardiograms (ECGs) of 10-second duration from 18,869 distinct patients.

* **Source**: [PhysioNet PTB-XL v1.0.3](https://physionet.org/content/ptb-xl/1.0.3/)
* **Authors**: Patrick Wagner, Nils Strodthoff, Ralf-Dieter Bousseljot, et al.
* **License**: Creative Commons Attribution 4.0 International (CC-BY 4.0)
* **Sampling Rates**: Available at both **100 Hz** (1,000 samples/lead) and **500 Hz** (5,000 samples/lead).
* **Storage Requirement**:
  * Compressed zip: ~1.7 GB (100 Hz records) / ~3.0 GB (full dataset with 500 Hz records).
  * Uncompressed on disk: ~3.5 GB.

### 2. Expected Directory Structure

Place or extract the raw PTB-XL files inside `dataset/ptb-xl/` such that the file tree matches:

```
mediguard-ai/
└── dataset/
    ├── ptb-xl/
    │   ├── ptbxl_database.csv      # Primary metadata, clinical annotations, and strat_fold
    │   ├── scp_statements.csv      # SCP-ECG diagnostic statement dictionary and superclass mapping
    │   ├── records100/             # 100 Hz WFDB signals (.hea and .dat files, nested by patient ID)
    │   │   ├── 00000/
    │   │   ├── ...
    │   │   └── 21000/
    │   └── records500/             # 500 Hz WFDB signals (optional, for full-resolution training)
    │       ├── 00000/
    │       └── ...
    └── processed/                  # Generated by ml/data_prep.py (split indices, statistics)
        ├── train.csv
        ├── val.csv
        ├── test.csv
        └── class_statistics.json
```

### 3. Step-by-Step Download Instructions

#### Option A: Direct Download via PhysioNet (Recommended)
1. Download `ptb-xl-a-large-publicly-available-electrocardiography-dataset-1.0.3.zip` from PhysioNet:
   ```bash
   # Linux / macOS / PowerShell
   curl -O https://physionet.org/static/published-projects/ptb-xl/ptb-xl-a-large-publicly-available-electrocardiography-dataset-1.0.3.zip
   ```
2. Unzip into `dataset/ptb-xl/`:
   ```bash
   unzip ptb-xl-a-large-publicly-available-electrocardiography-dataset-1.0.3.zip -d dataset/
   mv dataset/ptb-xl-a-large-publicly-available-electrocardiography-dataset-1.0.3 dataset/ptb-xl
   ```

#### Option B: Download via `wget` (Headless Server)
```bash
wget -r -N -c -np https://physionet.org/files/ptb-xl/1.0.3/ -P dataset/ptb-xl/
```

### 4. Fast Training with `--use-100hz`

The full PTB-XL dataset provides waveforms at both 500 Hz (standard clinical diagnostic bandwidth) and 100 Hz.

* For rapid development, debugging, and laptop execution, pass `--use-100hz`:
  ```bash
  python -m ml.train --use-100hz --epochs 10 --batch-size 64
  ```
* **Why 100 Hz?**
  * Input tensor per sample is $12 \times 1,000$ instead of $12 \times 5,000$ (5x smaller memory footprint).
  * Epoch execution speed is approximately $4\times - 5\times$ faster.
  * Published benchmark studies demonstrate that macro-AUROC on the 5 diagnostic superclasses differs by $< 0.015$ between 100 Hz and 500 Hz downsampled data.
